System Architecture

End-to-end medical NLP pipeline combining deep learning and transformer models.

01

File Extraction

Upload PDF, DOCX, or TXT medical reports. Text is extracted and cleaned using PyPDF2 and python-docx parsers.

PyPDF2 • python-docx
02

RAG Chunking

Long documents are split into overlapping chunks with sentence-boundary-aware splitting for optimal model input.

Overlap: 128 tokens • Chunk: 1024
03

LSTM Seq2Seq

2-layer stacked LSTM encoder-decoder with Bahdanau attention. Trained on CNN/DailyMail with teacher forcing (0.5).

PyTorch • Hidden=512 • Attention
04

BART Summarization

facebook/bart-large-cnn via HuggingFace Inference API for state-of-the-art abstractive summarization.

HuggingFace • BART • Beam Search
05

Clinical NER

BERT-based NER (dslim/bert-base-NER) + comprehensive medical keyword extraction for DISEASE, DRUG, SYMPTOM, TREATMENT.

BERT NER • i2b2 • Regex
06

ROUGE Evaluation

Automated ROUGE-1, ROUGE-2, ROUGE-L metric computation comparing generated summaries with source documents.

ROUGE-1 • ROUGE-2 • ROUGE-L

Technical Details

🧪 DL Objective — LSTM Seq2Seq

  • 2-layer stacked LSTM encoder (bidirectional, hidden=512)
  • Bahdanau attention between encoder states and decoder
  • Teacher forcing ratio = 0.5 during training
  • Adam optimizer with gradient clipping (max_norm=1.0)
  • Packed sequences for variable-length inputs
  • ROUGE-L target: 0.41
  • Ablation: attention vs no attention comparison
  • Trained on CNN/DailyMail (HuggingFace datasets)

🔬 NLP Objective — Transformers + NER

  • facebook/bart-large-cnn for abstractive summarization
  • BART ROUGE comparison vs LSTM-attention baseline
  • dslim/bert-base-NER for entity extraction
  • Clinical entity categories: DISEASE, DRUG, SYMPTOM, TREATMENT
  • Combined pipeline: summarize → extract entities
  • Side-by-side: raw report | summary | entities
  • Comprehensive keyword-based fallback NER

⚙️ Key Technologies

  • Backend: FastAPI, Python, Uvicorn
  • Deep Learning: PyTorch, LSTM, Seq2Seq
  • Transformers: HuggingFace, BART, BERT
  • NER: dslim/bert-base-NER + medical dictionaries
  • Metrics: ROUGE-1, ROUGE-2, ROUGE-L
  • File Processing: PyPDF2, python-docx
  • RAG: Sentence-boundary-aware chunking
  • Frontend: Vanilla HTML/CSS/JS
